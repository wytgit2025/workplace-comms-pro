# Workplace Comms Pro

> **写周报、给老板汇报、找别的部门帮忙——这些事最烦的不是写，是"想不起来这周到底干了啥"。**

一个跨 **飞书 / 钉钉 / 企业微信** 的中文职场内部沟通写作 Skill。自动汇总你在各办公平台上的工作痕迹，按中文职场分寸感，写成老板 30 秒能看完的内部沟通稿。

Anthropic 官方 [`internal-comms`](https://github.com/anthropics/skills) 的中文增强版。

## 解决什么痛点

- 周五下午想写周报，盯着空白文档想不起来这周干了什么
- 给老板汇报，写了三段铺垫他还不知道你要批多少钱
- 找法务帮忙，甩一句"在吗"，对方还得追问你什么事、什么时候要
- 每个平台一个待办，周报要来回切多个 app 抄数据

## 支持六种文体

| 文体 | 什么时候用 | 亮点 |
|---|---|---|
| 📋 周报 | "写周报""周五交周报" | 含极简三行版，发群里/站会直接用 |
| 📊 向上汇报 | "给老板汇报""月度汇报" | 结论先行、带方案抛问题 |
| 🚀 项目启动通知 | "kick-off""发个启动通知" | 背景/目标/范围/分工/时间点 |
| 🤝 跨部门求助 | "找XX部门帮忙" | 给足上下文、降低对方协作成本 |
| 📢 全员通讯 | "部门月报""公司newsletter" | 分板块、按重要性排、不是流水账 |
| ❓ 全员FAQ | "整理常见问题""新人问答" | 高频问题标准答案、减少重复沟通 |

## 七大数据源自动拉取

一个人一周的工作痕迹散落在任务、会议、群聊、审批、文档里。Workplace Comms Pro 自动从多平台拉取：

| 数据源 | 飞书 | 钉钉 | 企业微信 |
|---|---|---|---|
| 待办任务 | ✅ 任务 | ✅ 待办 | ✅ 待办 |
| 日程会议 | ✅ 日历 | ✅ 日程 | ✅ 腾讯会议 |
| 会议纪要 | ✅ 妙记 | ✅ 闪记 | ✅ 会议纪要 |
| 群聊记录 | ✅ 群消息 | ✅ 群消息 | ✅ 群消息 |
| 审批记录 | ✅ 审批 | ✅ 审批 | ✅ 审批 |
| 在线文档 | ✅ 云文档 | ✅ 钉钉文档 | ✅ 微盘文档 |
| OKR 对齐 | ✅ OKR | — | — |

拉到数据后自动与你对齐："我看到这周主要在做 A、B、C，对吗？"——避免漏事，也避免你重复输入。

## 写完直接落地

不只是给你一段文本让你自己复制——写完直接帮你发出去：

- 📄 写成飞书文档（`lark-doc`）
- 💬 发到群消息（`lark-im`）
- ✅ 把"下一步"建成跟进任务（`lark-task`）

## 和现有方案的区别

| 方案 | 局限 |
|---|---|
| Anthropic 官方 `internal-comms` | 英文、静态模板、不接中国办公平台 |
| 通用写作 prompt | 每次重新想结构、没有中文职场分寸感、不自动拉数据 |
| 手动整理周报 | 切多个 app 抄数据、容易漏事、写成流水账 |

**Workplace Comms Pro：跨三平台 + 七大数据源 + 中文职场分寸感 + 写完直接落地。**

## 快速开始

### 安装

把 `workplace-comms-pro/` 整个目录放到你的 Agent 技能目录下（如 `.user_skills/`），支持豆包工作、Claude Code、WorkBuddy 等兼容 Agent Skills 开放格式的环境。

### 使用

直接用自然语言说就行，不需要记指令：

```
帮我写个周报
给老板同步一下会员项目的进展
找数据部门帮忙拉个数
发个项目启动通知
```

Skill 会自动识别文体、拉取工作数据、按对应结构和分寸感成稿，写完直接帮你发出去。

## 项目结构

```
workplace-comms-pro/

    ├── upward-update.md              # 向上汇报
    ├── project-kickoff.md           # 项目启动通知
    ├── cross-team-request.md         # 跨部门求助
    ├── company-newsletter.md         # 全员通讯/部门月报
    └── faq-answers.md                # 全员FAQ
```
